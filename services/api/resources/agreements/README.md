# Agreement content

Place authorized Markdown at `<DOCUMENT_CODE>/<VERSION>.md`, matching an existing agreement document/version. The account agreement API returns plain text; clients render it as text, never executable HTML. Missing or hash-mismatched content is explicitly unavailable and cannot be accepted through the account page.

The checked-in versions are explicitly labeled CAPSTONE/TEST content authorized for the project demonstration. They must not be relabeled as production legal, regulatory, government, or provider approval. A production version requires its own authorized content and a new immutable version record; existing acceptance history is preserved.
