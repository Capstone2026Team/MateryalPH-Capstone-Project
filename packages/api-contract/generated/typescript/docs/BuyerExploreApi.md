## searchBuyerListings

> ListingSearchEnvelope searchBuyerListings(listingSearchRequest)



Item-Based search over MAT-02 eligible Tier 2 listings inside the radius; Directory Suppliers are never inventory. Browsing defaults to DISTANCE and a text query defaults to BEST_DEAL (SRS, a normalized weighted sum with the Buyer\&#39;s Item-Based weights). FAVORITES_FIRST is a separate explicit sort that never changes Best Deal. Best Price compares the MAT-03 normalized price of the same comparable group and canonical unit across in-stock offers in the radius and needs two Vendors. One card per listing, deterministic tie-breaking and a signed keyset cursor that rejects changed filters.
